第1章 函数、极限与连续
1.1 函数的概念
函数是描述变量之间依赖关系的数学工具。设 x 与 y 是两个变量，若对于变量 x 在某一范围内的每一个确定值，变量 y 按照某种对应法则总有唯一确定的值与之对应，则称 y 是 x 的函数，记为 y=f(x)，其中 x 称为自变量，y 称为因变量。使函数有意义的自变量的取值范围称为函数的定义域，因变量取值范围称为值域。
常见的函数类型包括幂函数、指数函数、对数函数、三角函数与反三角函数，统称为基本初等函数。由基本初等函数经过有限次四则运算与复合运算得到的函数称为初等函数。函数的表示方法有解析法、表格法与图像法。
函数的两个基本性质是单调性与奇偶性。设函数在区间内有定义，若对区间内任意两点，自变量增大时函数值也增大，则称函数在该区间内单调增加；若 f(-x)=f(x) 则称偶函数，图像关于 y 轴对称；若 f(-x)=-f(x) 则称奇函数，图像关于原点对称。
1.2 数列的极限
对于数列 {xn}，如果当项数 n 无限增大时，数列的项 xn 无限趋近于一个确定的常数 a，则称常数 a 为数列 {xn} 的极限，记为 lim xn = a。此时称数列收敛，否则称数列发散。
极限的 ε-N 语言定义：对任意给定的正数 ε，总存在正整数 N，使得当 n>N 时，恒有 |xn-a|<ε，则称 a 是数列 {xn} 的极限。
收敛数列具有唯一性、有界性与保号性三个重要性质。若数列收敛，则其极限唯一；收敛数列必有界；若数列从某项起的值非负且收敛于 a，则 a≥0。
1.3 函数的极限
当自变量 x 趋近于某一点 x0 时，若函数值 f(x) 无限趋近于常数 A，则称 A 为函数 f(x) 当 x→x0 时的极限，记为 lim f(x)=A。极限的 ε-δ 定义：对任意给定的正数 ε，总存在正数 δ，使得当 0<|x-x0|<δ 时，恒有 |f(x)-A|<ε。
当自变量 x 趋于无穷大时，若 f(x) 无限趋近于常数 A，则称 A 为函数在无穷远处的极限。函数极限存在时，其极限值唯一。
函数在一点处的极限与函数在该点的函数值没有必然联系。函数在某点存在极限，只要求自变量趋近该点时函数值有稳定趋势，并不要求函数在该点有定义。
1.4 极限的性质与运算法则
极限具有四则运算法则：若两个函数在自变量的同一趋近过程中都存在极限，则它们和、差、积、商的极限等于极限的和、差、积、商（除法时分母极限不为零）。利用这些法则可以简化许多极限的计算。
极限的夹逼准则：若函数 g(x)≤f(x)≤h(x)，且 g(x) 与 h(x) 的极限都等于 A，则 f(x) 的极限也等于 A。夹逼准则是判断极限存在并求极限的重要工具。
单调有界准则：单调有界的数列必有极限。这一准则常用于证明数列收敛，例如自然对数的底 e 的定义就依赖于该准则。
1.5 两个重要极限
第一个重要极限：当 x→0 时，sin x / x 的极限等于 1。该极限揭示了三角函数在零点附近与线性函数的等价关系，是求含三角函数的极限的基础。
第二个重要极限：(1 + 1/n) 的 n 次方当 n 趋于无穷时的极限等于自然常数 e；更一般地，(1+x) 的 1/x 次方当 x→0 时极限也为 e。该极限广泛用于经济学中的复利计算与自然增长模型。
利用两个重要极限可以将许多复杂极限转化为标准形式，从而求出极限值。例如求 tan x / x 在 x→0 时的极限，可将 tan x 改写为 sin x 与 cos x 的商，再利用第一个重要极限。
1.6 无穷小与无穷大
如果函数 f(x) 在自变量的某一趋近过程中的极限为零，则称 f(x) 为该过程中的无穷小量。有限个无穷小量的和、积仍为无穷小量；有界函数与无穷小量的乘积仍为无穷小量。
如果函数 f(x) 的绝对值在趋近过程中无限增大，则称 f(x) 为无穷大量。无穷小量与无穷大量之间具有倒数关系：非零无穷小量的倒数是无穷大量，无穷大量的倒数是无穷小量。
比较无穷小量时，若两个无穷小量之比趋于零，则称分子是分母的高阶无穷小；若比值趋于非零常数，则称两者为同阶无穷小；若比值趋于 1，则称两者为等价无穷小。在求极限时，可用等价无穷小替换化简计算，但必须注意替换条件：仅在乘除因子中可以直接替换，加减项中一般不可随意替换。
第2章 连续
2.1 函数连续的概念
设函数 f(x) 在点 x0 的某邻域内有定义，若当 x→x0 时，f(x) 的极限存在且等于 f(x0)，即 lim f(x)=f(x0)，则称函数 f(x) 在点 x0 处连续。连续的本质是"极限值等于函数值"。
函数在某点连续的充要条件是：函数在该点的左极限、右极限与函数值三者都存在且相等。若函数在区间内每一点都连续，则称函数在该区间上连续。
连续函数具有局部有界性、保号性等性质。连续函数的图像是一条没有间断点的连续曲线，这也是"连续"名称的由来。
2.2 间断点及其分类
如果函数在点 x0 处不连续，则称 x0 为函数的间断点。间断点按其性质可分为两类：
第一类间断点：函数在该点的左极限与右极限都存在。若左右极限相等但不等于函数值或函数无定义，称为可去间断点；若左右极限不相等，称为跳跃间断点。
第二类间断点：函数在该点的左极限与右极限至少有一个不存在。典型例子包括无穷间断点（如 y=1/x 在 x=0 处）与振荡间断点（如 y=sin(1/x) 在 x=0 附近无限振荡）。
判断间断点类型的步骤：先求左右极限，左右极限都存在则属于第一类，进一步比较左右极限是否相等判断可去或跳跃；若某侧极限不存在则为第二类。
2.3 连续函数的运算与初等函数的连续性
连续函数经过有限次四则运算后仍然连续（除法时分母不为零）；连续函数的复合函数仍然连续。这一性质使得我们可以通过已知的连续函数构造出大量连续函数。
基本初等函数在其定义域内都是连续的，因此初等函数在其定义区间内连续。求初等函数在某点的极限时，若该点在定义域内，可直接代入函数值计算，这是求极限的常用方法。
2.4 闭区间上连续函数的性质
最值定理：闭区间上的连续函数一定有最大值和最小值。即闭区间上的连续函数既能取到最大值也能取到最小值，这是求函数最值问题的理论基础。
介值定理：设函数在闭区间上连续，若端点函数值异号，则函数在区间内至少存在一点使函数值为零，该定理也称为零点定理。介值定理的推广：连续函数能取到最大值与最小值之间的一切中间值。
零点定理在方程求根中应用广泛：判断方程在区间内是否有实根，只需检验区间端点函数值是否异号。若异号，则区间内至少存在一个实根。
