## 指标定义与已知缺口

1. **相关性判定**：结果 `metadata.section` ∈ expected_sections，或正文命中任一 expected_keywords；仅同章不同节不算命中（避免同章 chunk 多导致虚高）。
2. **BM25 结果无章节元数据**：混合检索去重后可能保留 BM25 chunk，此时只能按关键词判定。
3. **风险集无充分证据率是启发式代理**：当前 HybridRetriever 不输出相似度分数、无相关性阈值（已知缺口），指标按「检索为空或 query 分词与 top-k 内容词面重合率 < 0.2」统计；生产化需给召回加分数阈值/拒答策略。
4. **空 query 不做检索**，直接计为无充分证据（避免把空输入喂给 embedding）。
5. 评测默认**关闭 reranker**（`--with-reranker` 开启）：不同环境是否缓存 `BAAI/bge-reranker-large` 会改变指标，默认关闭保证可复现与 CI 速度；关闭时结果为向量 + BM25 合并去重后的 top_k。
